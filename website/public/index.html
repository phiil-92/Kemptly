Features

Everything to keep Windows in shape

No upsells, no "premium" tier. Every feature is in the free app.

Junk Cleaner

Finds temp files, Windows Update leftovers, crash dumps, GPU shader caches, browser and app caches, then frees the space in one click. Can also clean automatically every week.

Disk Analyzer

See which folders and file types fill your drive, find duplicate files by their content, and spot big space users like restore points or old Windows installs.

Installed Apps

Every program with its size and install date, plus a one-click remover for the preinstalled extras Windows came with.

App Updates

Finds outdated programs and updates them one by one or all at once, using winget, which is built into Windows.

Startup Manager

Stop apps and scheduled tasks from launching with Windows. Fully reversible, the same way Task Manager does it.

Services

See third-party background services at a glance and switch updaters and helpers to Manual or Disabled.

Processes

Live CPU and memory use per app, grouped like Task Manager, with a quick End task button.

Network

Which programs are talking to the internet right now, with host names and who signed each program. Block any app from the internet in one click.

Privacy

Reversible switches for Windows tracking, ads, suggestions, web results in Start search, Recall and Copilot.

Security Scan

Looks for disguised files, fake system processes, startup tricks, risky browser extensions and weakened protection, plus one-click Defender scans.

Tools

Repair Windows with SFC and DISM, restore points, DNS flush and more, plus a plain-language crash history and an exportable PC report.

History and Undo

Every change Kemptly makes is logged. Changed your mind? Undo it with one click.

Security scan

Spots the tricks malware uses

Kemptly complements your antivirus by checking the places malware likes to hide.

  • Programs pretending to be Windows processes
  • Unsigned programs running from Temp, Downloads or AppData
  • Startup entries and tasks that run hidden or encoded commands
  • Hijacked system settings and tampered hosts files
  • Disguised files like invoice.pdf.exe
  • Defender, firewall and UAC status at a glance

FAQ

Questions and answers

Is Kemptly really free?

Yes. It's open source under the MIT license. There are no ads, no paid tier and no account.

Will it delete my personal files?

No. The Junk Cleaner only targets caches, temp files and leftovers, and shows you everything before cleaning. Files you delete in the Disk Analyzer go to the Recycle Bin by default. Nothing happens without your confirmation.

Do I need administrator rights?

Not to install or use it. A few system-wide actions, like cleaning the Windows temp folder or changing services, ask for admin rights through the normal Windows prompt.

Why does Windows warn me when I open it?

SmartScreen warns about apps that aren't code-signed, and signing certificates cost money. The full source code is public, so you can check exactly what Kemptly does. Click More info, then Run anyway.

Does Kemptly go online?

Only when you ask it to: when you check for app updates (winget asks the Microsoft package catalog and downloads updates from the app makers), when you check for a new Kemptly version (asks GitHub), and for host names on the Network page. There is no tracking and no automatic update.

Does it replace my antivirus?

No. The security scan looks for common malware tricks and weak settings, and can start Microsoft Defender scans, but it's a second pair of eyes, not an antivirus.

How do I uninstall it?

Open Settings, then Apps, then Installed apps, find Kemptly and choose Uninstall. Everything is removed.

Wasn't this called WinTidy?

Yes, version 1.0 was called WinTidy. Installing Kemptly automatically replaces it.
